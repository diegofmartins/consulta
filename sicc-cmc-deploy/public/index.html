Configuração de APIs governamentais

O token é gerado automaticamente pelo gateway do SERPRO. Em produção, confirme se o plano de consumo do órgão está ativo.
A API da CGU pesquisa sanções nos cadastros CEIS (inidôneas e suspensas) e CNEP (Lei Anticorrupção). Para gerar uma chave gratuita, acesse Cadastro de e-mail na CGU.
Demais APIs em uso
  • BrasilAPI (Receita Federal): aberta e gratuita, sem chave.
  • Compras.gov.br (SICAF): dados abertos oficiais, sem chave.
  • SERPRO (CND): API oficial, exige consumer key e consumer secret.
  • TST (CNDT): emissão direta com desafio e validação automática.
